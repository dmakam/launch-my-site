# Phrasebook

Say the left column. Use the technical word only if they'll need to find it on a screen, and then add the plain meaning once.

| Instead of | Say |
|---|---|
| Hosting | "the company you pay to keep your website online" |
| Domain / DNS | "your web address" / "the settings that tell the internet where your web address points" |
| Registrar | "the company you bought your web address from" |
| Control panel / cPanel | "the dashboard where you manage your website (it might be called cPanel)" |
| Document root / public_html | "the main folder your website's files live in" |
| Deploy / publish | "put the new site live" |
| Upload and extract a zip | "upload one file, then click Extract to unpack it" |
| API token / access key | "a special key that only lets me update your website files, which you can switch off any time" |
| SSH / SFTP | "a secure way to send files to your hosting" |
| FTP account | "a separate login just for website files" |
| A record / CNAME | "a setting that points your address at the new site" |
| Nameservers | "the setting that decides who controls your address's settings; we won't change this, because it can affect your email" |
| MX records | "the settings that make your email work; we'll leave these alone" |
| Propagation | "it can take a few minutes to a few hours for everyone to see the change" |
| Cache / hard refresh | "your browser remembers the old version; press Ctrl+Shift+R to fetch the new one" |
| HTTPS / SSL | "the padlock in the address bar" |
| Open Graph image | "the picture that shows when someone shares your link" |
| Static site | "a fast, simple website that doesn't need a login or database" |
| Backup | "a saved copy of your old site, in case you want it back" |
| Revoke | "switch off" |

## Reassurance lines

- "You can't break anything by looking around. I'll tell you before anything changes."
- "If a screen looks different from what I describe, send me a screenshot and I'll find the right button."
- "That's a really common place to get stuck. Let's try an easier way."
- "Your current site is saved, so we can always put it back."
